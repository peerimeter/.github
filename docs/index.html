Agent

Go WireGuard agent for Linux, macOS and Windows. Connects peers directly and can join a service-managed network.

Self-hosted API for creating WireGuard networks, registering nodes and sharing peer configuration.

macOS

Windows

Bundled signed WireGuardNT driver and native Windows Service.

Install Peerimeter Agent

Install with the recommended defaults. The installers verify release checksums.

irm https://agent.peerimeter.app/install.ps1 | iex

Quick setup

Deploy the service, then install the agent on Linux or macOS and register it to a network:

curl -fsSL https://agent.peerimeter.app/install.sh | sudo sh

export SERVICE_URL='https://service.example.com'
read -rsp 'Service API key: ' SERVICE_API_KEY; printf '\n'

# Create a network with a WireGuard address pool.
curl -fsS "$SERVICE_URL/api/v1/networks" \
  -H "Authorization: Bearer $SERVICE_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"version":1,"id":"home","name":"Home","cidr":"10.90.0.0/24"}'

# Get a join token and pass it to the agent via stdin.
curl -fsS "$SERVICE_URL/api/v1/join-bundle?network_id=home" \
  -H "Authorization: Bearer $SERVICE_API_KEY" \
  | jq -er '.token' | sudo peerimeter-agent join

The service uses a shared API key; keep join tokens private. The agent uses the machine hostname as its node ID by default. Read the full setup guide for deployment details and Windows instructions.
