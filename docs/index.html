A headless WireGuard agent for Linux, macOS and Windows. Configure peers locally and connect directly, without a required control plane or relay.

Install the agent View source
Release status: installer endpoints are published, but no public agent release exists yet. The scripts will install the agent after the first release is published.

Linux

Kernel WireGuard and systemd. Install the agent with the shell script.

macOS

Native utun through the embedded WireGuard backend, managed by launchd.

Windows

Bundled signed WireGuardNT driver and native Windows Service.

Install Peerimeter Agent

Installers verify release checksums. Choose a version and install path with the documented script options.

Linux

curl -fsSL https://agent.peerimeter.app/install.sh | sudo sh

macOS

curl -fsSL https://agent.peerimeter.app/install.sh | sudo sh

Windows PowerShell (Run as Administrator)

irm https://agent.peerimeter.app/install.ps1 | iex

For Linux/macOS pipe installs, pass options after sh -s --, for example curl -fsSL https://agent.peerimeter.app/install.sh | sh -s -- --install-dir "$HOME/.local/bin" or curl -fsSL https://agent.peerimeter.app/install.sh | sudo sh -s -- --version v0.1.0 --install-dir /usr/local/bin. Windows: ./install.ps1 -Version vX.Y.Z -InstallDir 'C:\Tools\Peerimeter'.
