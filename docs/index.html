Install Peerimeter Agent

Installers verify release checksums. Choose a version and install path with the documented script options.

Linux

curl -fsSL https://agent.peerimeter.app/install.sh | sudo sh

macOS

curl -fsSL https://agent.peerimeter.app/install.sh | sudo sh

Windows PowerShell (Run as Administrator)

irm https://agent.peerimeter.app/install.ps1 | iex

Choose a version or install directory

Linux / macOS · user install 
curl -fsSL https://agent.peerimeter.app/install.sh | sh -s -- --install-dir "$HOME/.local/bin"
Linux / macOS · system-wide, pinned version 
curl -fsSL https://agent.peerimeter.app/install.sh | sudo sh -s -- --version v0.1.0 --install-dir /usr/local/bin
Windows PowerShell · one-liner with options (Run as Administrator) 
& ([scriptblock]::Create((irm 'https://agent.peerimeter.app/install.ps1'))) -Version v0.1.0 -InstallDir 'C:\Tools\Peerimeter'

For a downloaded script, use .\install.ps1 -Version v0.1.0 -InstallDir 'C:\Tools\Peerimeter'. Piping the script to iex runs it with defaults; iex does not forward installer parameters.
