A headless WireGuard agent for Linux, macOS and Windows. Configure peers locally and connect directly, without a required control plane or relay.

Install the agent View source
Release status: the installer endpoints are being prepared. A public agent release has not been published yet, so installation will become available with the first release.

Linux

Kernel WireGuard and systemd. Install the agent with the shell script.

macOS

Native utun through the embedded WireGuard backend, managed by launchd.

Windows

Bundled signed WireGuardNT driver and native Windows Service.

Install Peerimeter Agent

Installers verify release checksums. Choose a version and install path with the documented script options.

Linux

curl -fsSLo install.sh https://agent.peerimeter.app/install.sh
chmod +x install.sh
sudo ./install.sh

macOS

curl -fsSLo install.sh https://agent.peerimeter.app/install.sh
chmod +x install.sh
sudo ./install.sh

Windows PowerShell (Run as Administrator)

Invoke-WebRequest https://agent.peerimeter.app/install.ps1 -OutFile install.ps1
.\install.ps1

Custom version and destination: ./install.sh --version vX.Y.Z --install-dir /absolute/path or ./install.ps1 -Version vX.Y.Z -InstallDir 'C:\Tools\Peerimeter'.
